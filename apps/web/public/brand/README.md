# RentBond brand assets

Source: the team's `rentbond-brand-kit-curve.zip`, supplied on 2026-10-04. Original assets are copied unchanged from the supplied package; no font files are distributed.

- `logo-horizontal-nav.svg`: navigation variant retaining the supplied path geometry and white outlined wordmark, with the original charcoal/gold symbol on a cream tile for contrast. Replaces the all-white navigation symbol at the user's request.
- `logo-horizontal-white.svg`, `icon-color.svg`: original source artwork retained for reference; no separate account-panel logo is displayed.
- `favicon.ico`: browser tab icon.
- `app-icon-180.png`: Apple touch icon.

Preserve the original proportions and clear space. Brand colors do not encode deposit allocation or transaction status. The package describes the wordmark as outlined Avenir Next Demi Bold and the symbol as redrawn geometry based on an AI-assisted reference; final branding rights/attribution remain part of the submission review.
