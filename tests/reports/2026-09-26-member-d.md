## Failures Found And Corrected

- An invalid decimal amount reached BigInt before schema rejection. The validation pipeline now returns 422.
- Optional undefined draft fields broke canonicalization during edits. Draft merging now omits absent fields.
- Checksummed vs lowercase addresses prevented otherwise valid service documents matching on-chain parameters. Semantic address comparison is normalized while the original committed document stays unchanged.
- viem's default block-number cache caused stale confirmation status after rapid transactions. Permission/status reads now disable the cache.
- Next's bundler treated the migration directory URL as an import. Migration path resolution and the explicit repository tracing root fixed the build.
- The original shared commitment helper used SHA-256 despite the Keccak requirement. A single shared salted implementation and fixed vector replace it.
- The existing EvidenceAcknowledged event lacks the document bundle identity. API labels now use the exact contract record, not an ambiguous event match.
- The existing Next dependency and initially selected tooling had published advisories. Exact patched versions/overrides were installed and audited.

No failed run was reclassified as passed; the rows above refer to subsequent successful checks.
