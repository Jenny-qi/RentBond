# ADR 0001 产品展示与五人协作基线

状态：采用于启动框架，2026-09-21 更新定位措辞。依据：用户要求与补充分享内容，不代表业务完成或全体成员签名。

## 决定

保留 v1.2 资金/权限/期限工程规则；新增独立 MVP 展示规格，强调跨境租客远程退租与 700/100/200 部分结算。国际学生、海外工作者、陪读／随迁家庭是首批场景，不把产品限制为学生身份。主展示三角色，底层保留 F、预授权、超时和恢复。

原四类职责拆成五人：产品、合约、前端账户、后端数据、集成质量。保留 monorepo 和既定技术主栈。当前先交启动包，不一次生成未经验证的业务系统。

## 语义冲突处理

“立即释放”按“不等争议处理结束”表达，仍受 claimDeadline 与链确认约束。展示工程术语简化，但不隐藏授权/存入区别、金额确认和失败。对应 FR-05/08/19/20/31、SC-12、AT03/12/26/41。

## 影响

README、MVP、team、backlog、Demo 和 fixtures 更新。合约金额、签约范围及资金权利未改变，因此没有迁移已有租约的工作。未来改这些规则另建 ADR。
