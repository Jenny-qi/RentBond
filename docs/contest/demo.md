# 三角色主 Demo 与工程附录

负责人 A，C 做展示、B/E 准备真实数据。时间为内部建议，实际视频长度由比赛规则决定。

## 主演示约三分钟

1. **问题与前提（20秒）**：Alice 是跨境租客，退租时已离开当地；入住前双方已采用本流程并存入 1,000 MockUSD。明确测试资产。
2. **房东（30秒）**：逐项清洁100、桌面损坏200，有理由与材料；一次提交不是直接扣款。
3. **租客（35秒）**：通行密钥进入，认可清洁100并明确确认，争议入住时已存在的划痕200。
4. **核心画面（40秒）**：先展示预计拆分。使用明确 DEMO_SHORT 的真实期限；窗口关闭并执行 closeClaims 后展示700可领/100可领/200待处理。不能伪造时钟或跳过链交易。
5. **处理与领取（45秒）**：Resolver 给出有理由结果50给房东、150给租客；挑战期到且无人挑战后生效。展示双方领取交易与最终850/150。若镜头剪辑等待，明确时间跳转与交易。
6. **解释（10秒）**：数据库负责协作；合约把预先同意的分配权限绑定到已存入资金，平台不能改一行数据转走钱。

讲解避免未经证实的“传统机构都会冻结整笔”或“我们技术首创”。可以强调设计目标：一项争议不应阻止已可分配部分领取。
