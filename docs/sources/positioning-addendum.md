# 用户补充定位记录

来源：2026-09-18 至 2026-09-21 用户直接提供的定位建议，以下为忠实摘要，不是新增用户研究。

- 不只面向留学生，而是聚焦跨境租房、即将退租或已经离境、需要远程处理押金的人群。
- 首批场景包括国际学生、海外工作者、陪读／随迁家庭；身份和年龄不是准入条件。
- Adoption-side user 为经常服务跨境租客的私人房东和小型物业；已有成熟押金系统的大型机构公寓不作为最初重点。
- 核心场景是多项扣款中只认可一部分，希望无争议部分先退、争议部分单独保留。
- 面向双方提供透明、可执行的结算流程，不做单方面对抗房东的工具。
- 英文定位：For people renting abroad, especially when move-out and deposit settlement happen remotely.
- 当前研究不能证明全球跨境租客存在同样情况，应说 initial target scenarios，不宣称已验证全球需求。

用户建议中的“立即释放”与附件同样按PRD期限解释，具体落实见MVP-SPEC。对于已经离境的案例，入金前仍必须先有双方确认及真实合约存入。
