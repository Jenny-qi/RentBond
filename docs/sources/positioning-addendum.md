# 用户补充定位记录

来源：2026-09-18 当前任务中用户直接提供的定位建议，以下为忠实摘要，不是新增用户研究。

- 不面向抽象的“所有留学生”，先聚焦跨境租房、即将退租或已经离境、需要远程处理押金的国际学生。
- 初始租客画像18–28岁，初次或前几次海外租房，向私人房东或小型物业承租；年龄只是画像。
- Adoption-side user为经常出租给国际学生的私人房东和小型物业；大型机构学生公寓已有成熟系统，不作为最初重点。
- 核心场景是多项扣款中只认可一部分，希望无争议部分先退、争议部分单独保留。
- 面向双方提供透明、可执行的结算流程，不做单方面对抗房东的工具。
- 英文定位：For international students renting abroad, especially when move-out and deposit settlement happen remotely.
- 当前研究不能证明全球学生存在同样情况，应说 initial target segment，不宣称已验证全球需求。

用户建议中的“立即释放”与附件同样按PRD期限解释，具体落实见MVP-SPEC。对于已经离境的案例，入金前仍必须先有双方确认及真实合约存入。
