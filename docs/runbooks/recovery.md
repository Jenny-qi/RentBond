# 故障与停运恢复计划

负责人 E，B/C/D 各负责链上/账户/数据。当前是待实测计划，AT51 尚未通过。

| 故障 | 处理与验收 |
| --- | --- |
| RPC 中断或不同链 | 保留最后成功状态及时间；禁用写入，验证备用同链后恢复；不显示余额零 |
| DB 故障而链上成功 | 从部署块/检查点重放，事件幂等写入；不人工伪造交易 |
| 非规范区块 | 用 blockHash 定位并撤销相关投影，再重建 |
| Worker 停止 | 用户/第三方可公开推进；重启不延期限、不重复分配 |
| 私有存储不可用 | 明确资料暂不可用；不发公开永久链接绕过权限；备份恢复后核验承诺 |
| 费用补给停止 | 独立第三方提供测试费用；不代签当事人、不挪押金付 Gas |
| 账户恢复失败 | 不新建地址冒充原角色；记录失败，不能宣称停运恢复通过 |
| 凭据泄漏 | 撤销/轮换相关服务凭据、追查日志与访问；不能靠新网页修改旧合约受益人 |

## AT51 独立恢复演练

停止主站、API、DB、Worker 和官方补给。独立工具只依赖公开网络、真实部署记录及原账户恢复机制。读取原合约，检查资金/期限，按既定规则公开推进；第三方承担费用调用 withdrawFor，支付给固定 T/L。核对原账户余额与交易，记录整个演练。

恢复工具须由 RB-12/13 实现，不能依赖主站同一域名服务才能加载的页面。尤其要验证 passkey 原地址访问在主站故障时是否仍可行；若不可行，AT51 失败而非文档豁免。
