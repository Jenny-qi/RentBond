# 测试网发布手册草案

负责人 E/B；已有用户通过 Remix 手动部署的测试网合约和一笔入金，详见 [只读链上证据](../../deployments/README.md)。当前并无完整的 700/100/200 测试网结算或独立审查，不能据此宣称测试网产品可用。本清单仍用于后续正式发布。

1. 确认正式比赛资格、P0 结果、固定源码 commit、工具版本和迁移版本。
2. 本地链跑完核心及异常用例；测试网部署前读取 eth_chainId，与经核查配置一致。
3. 使用独立部署账户；部署 MockUSD、Registry、Factory，注册 R/F 服务；保存部署交易、区块、ABI/源码摘要。
4. DEMO_SHORT 与正常测试配置分开部署/记录，页面明确标示，不提供随意修改时间的后台。
5. 数据库迁移前备份；默认私有 Storage，校验匿名/无关租约/F未升级均拒绝。
6. 配置 Next.js 与独立 Worker，确认 RPC fallback 同链、事件检查点和重试幂等。
7. 从真实 UI 完成创建至领取，核对余额、交易、截图和 AT 记录；另一成员按 README 复现。
8. 固定 release，填写部署记录、Demo 链接、测试报告与已知限制。

前端可回退版本，迁移采用可兼容追加；不可升级合约不能通过前端回退改规则。需要新规则时部署新版本，旧租约仍按旧规则处理。任何关键资金或权限用例失败，停止本次发布。
